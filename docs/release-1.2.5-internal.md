# 地垫工作台 1.2.5 本地内测修复

2026-09-22 交付（09-21 开始修复）。修复商品转表复核页面在表格区域无法上下滚动的问题。上一轮检查验证了数据和布局，但漏掉鼠标处于长表格上的真实滚动交互。

## 原因与修复

商品表容器没有限定高度，内容随整页展开，却设置了双方向 overscroll-behavior: contain。容器本身不能纵向滚动，又拦截向父页面传递滚动，导致鼠标位于表格时页面不动。本版保留横向 contain，将纵向设为 auto；不调整数据计算、导入识别或保存逻辑。

原版真实 60 行表复现：发送向下滚轮后页面 scrollY 始终为 81，表格 clientHeight 与 scrollHeight 均为 8879。修复后同一测试通过。

- 140 行两页样本：用滚动输入到达分页按钮并切到第 2 页 40 条。
- 滚动前后复核行逐字段相同，业务工作区完全不变，无脚本错误。
- 411 项自动化测试、JavaScript 语法和运行清单检查通过。专项回归脚本保存在 scripts/release-validation/verify-product-scroll.cjs。
- 专项测试运行在隔离数据库中，不写入用户业务库。
