商品转表、定价、可复用规则及界面更新：

- 材质、厚度、尺寸分开复核，材质和尺寸支持留空；支持同商品链接批量处理、未写厚度筛选及多工作表映射。
- 新增可编辑、可保存的阶梯毛利、统一毛利和面积递增定价方案，手动改价后切回手动模式。
- 尺寸组合、定价及活动方案统一在可复用规则管理；增加折扣、直减的上架价格计算器。
- 增加大表流式处理、分页复核、销售表导入和数据恢复保护，优化规格弹窗与正式界面。
- 修复商品规格少于模板行数时，导出商品表可能出现 G62 共享公式错误的问题。
- 修复平台商家编码被内部空白编码覆盖，以及大表末页查询过慢的问题。

Windows 安装版可在应用内选择“检查更新 → 下载 → 重启安装”。升级保留已有数据；首次使用或旧 ZIP 版请下载安装包。
