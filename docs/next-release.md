## 商品转表：G62 共享公式导致导出失败

| 项目 | 记录 |
| --- | --- |
| 反馈日期 | 2026-09-18 |
| 复现版本 | 本机服务实际版本 1.1.8；界面固定显示 1.1.1。修复前的工作区源码也可复现 |
| 复现文件 | 《华住 9.18.xlsx》，60 条商品规格 |
| 触发步骤 | 进入商品转表，上传原表，等待显示 60 条原始规格、0 条待复核、可导出，再点击“导出商品表” |
| 错误原文 | `Shared Formula master must exist above and or left of clone for cell G62` |
| 影响 | 商品读取和计算成功，生成 Excel 时失败；不是原表格式错误 |
| 修复位置 | [public/product-transfer.js](../public/product-transfer.js) 的 `exportWorkbook` |
| 回归测试 | [test/product-transfer.test.js](../test/product-transfer.test.js) |

内置模板含 100 条示例数据。旧逻辑通过一次 `spliceRows` 删除末尾多余行，但当前内置 ExcelJS 对末尾多行删除没有生效。写入 60 条静态结果后，G62 等残留单元格仍引用已被覆盖的共享公式主单元格，导致导出失败。

修复改为从最后一行开始逐行删除，彻底移除多余模板行。保留原有字段映射、材料计算、模板样式和文本 ID。
