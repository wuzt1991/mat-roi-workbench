## 商品转表最新合同

以用户《商品转表(1).xlsx》为准，保留 29 列与顺序：

序号、平台、店铺、平台商品名称、平台规格名称、品牌、商品标签、尺寸、面积、宽、长、重量、成本、广告费、成交金额、主条码、规格辅助码、平台商品ID、平台规格ID、平台售价、售卖状态、平台库存、规格类型、规格名称、货品编码、货品简称、货品名称、商家编码、规格简称。

F 材质→品牌；G 厚度→商品标签；N 推广费→广告费；O 销售额→成交金额；P/Q 主条码与规格辅助码全部留空，不生成条码。29 列之外不新增输出。兼容旧表头输入；旧会话导出也按最新表头并清空两列条码。长编号保持文本，不改成本、重量与复核语义。

## 销售导入最新合同

- 默认读取“商品成交订单数”；“商品成交件数”仅在明确切换并确认一单一件估算后使用。不是独立订单号去重。
- 从 SKU 标题识别尺寸并统一单位，长宽互换视为相同尺寸；合并所有图案。存在多个平台、店铺或商品来源时先选择一个来源。
- 无尺寸、多尺寸、计划内重复尺寸需要人工映射或排除；计划缺失的尺寸需明确确认本次按 0。分母为已纳入数量，按百分之一分配舍入余数使合计 100%，全零拒绝。
- 识别出的明确尺寸在计划中缺失时可一键暂存新增规格；无尺寸、多尺寸、计划内重复尺寸不自动新增。应用时新增规格与销量、订单占比、来源记录一起保存，不覆盖已有售价和原商品/SKU 编号；支持撤销。排除记录计数按尺寸组保存。
- 暂时关闭保留本次运行中的复核，未应用时拦截退出/重启；“放弃本次导入”释放保护。未应用的选择不承诺跨重启恢复。
- 工作区/计划/尺寸变化拒绝旧候选；销毁后的迟到响应不得污染新窗口；同一导入编号的不同内容不能误报已保存。
