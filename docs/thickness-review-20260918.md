沿用现有工作台的侧栏、配色和表格样式。当前版本为 rev=9：转表页取消顶部方案选择和保存，使用“更多筛选 → 未写厚度 → 勾选 → 批量处理所选”完成补填。所有数据是内存示例，刷新重置，不读取或修改正式数据库及既有原型草稿。

可体验的流程：

1. 自动识别唯一有效厚度；未写、未知、多候选及伪亚麻进入人工复核。
2. 表格工具栏的“更多筛选”默认收起，点击后左侧保留“全部规格 / 待复核 / 已确认”，右侧显示同样样式的“未写厚度”；原“更多筛选”变为单独的向左收起箭头，位于“未写厚度”之后、筛选项最右端。没有复选框或下方独立面板。窄屏时工具栏自然换行，选项仍保持同级样式。筛选依据是原文没有厚度候选，不包含未知 8 mm 或 3/5 mm 冲突。手动补齐后仍属于原文未写，可结合“待复核”只看待处理行。
3. 全选及商品组勾选仅选当前可见行，切换筛选或修改行后剔除隐藏行的勾选；不恢复之前隐藏的选择。折叠筛选不清除条件，按钮保留“未写厚度”提示；展开可清除条件。
4. 用既有综合批量弹窗填材质、厚度或尺寸，默认保留已确认字段，不同材质的厚度不会套用错规则。商品 ID 行的材质、厚度下拉框直接作用于该商品全部 SKU，包括筛选隐藏行；行内注明隐藏条数，提示及页脚说明范围。
5. 材质和尺寸可明确留空；同商品统一材质、厚度时，尺寸默认各自保留。重量成本即时重算。
6. 全部复核后可预览并下载示例 CSV。导出条件始终检查所有行，不因筛选后的列表为空而放行。

已删除“识别与确认方案”列表、新增、编辑、复制、删除及恢复入口和相关弹窗、事件。商品转表使用自动识别；缺失或异常进入人工复核，通过筛选、逐行选择和批量处理完成。独立原型的规则页仅展示参与计算的材质、厚度、重量系数和成本。完整工作台原型中的定价、尺寸、活动等规则仍保留；原型合并未修改正式业务代码；已确认合同已于2026-09-19补录。旧模式算法暂保留在原型模型作历史验证，不在当前页面提供选用或配置入口。

## rev=8 筛选同级化与 rev=5 商品行内批量处理

- 商品 ID 行分列显示材质和厚度下拉框，对齐 SKU 对应列，替换原“批量处理此商品”按钮。
- ID 后显示“同链接批量处理”；超过 10 个字符显示前 6 位、后 4 位及省略号，悬停可查看完整值，辅助技术使用完整标签。数据和分组键始终保留完整 ID。
- 直接选择会统一该链接全部 SKU 的对应字段，包括已确认项和筛选隐藏项；尺寸始终保持。行下显示 SKU 数，存在隐藏行时明确数量。任意勾选的批量弹窗仍默认只补待确认项。
- 多材质、材质未确认时组厚度禁用，先统一材质。材质留空或全组尺寸留空时无需计算；部分尺寸留空时只给其余 SKU 填厚度，不回填留空尺寸。
- 材质变更沿用模型失效规则：清除不匹配厚度、等待人工选厚度。手动统一材质可明确处理伪亚麻；不自动猜测。
- 每次同链接修改提供一次“撤销”，仅撤销最近一次操作；后续数据修改使旧撤销失效，避免覆盖后续编辑。
- 12 项模型测试及 10 组浏览器验证通过；覆盖筛选同级按钮、展开/收起箭头、分列对齐、组内外范围、筛选隐藏行、尺寸保护、混合材质、材质留空、伪亚麻、撤销与旧撤销失效、长 ID 显示相同但不混组，以及三种视口宽度。

## rev=2–3 历史记录（已被后续反馈替代，不作为施工要求）

以下方案模式、默认自动填写、全组勾选和额外入口均只记录当时探索，当前行为以本页rev=9概述及C07为准。

上一版独立厚度入口造成批处理能力回退。本轮恢复完整复核层级：

- 表格及方案编辑均并列材质、厚度、尺寸；三个字段可分别设置自动或人工确认，厚度另支持缺失默认值。顶部重复的三个批量入口已按后续反馈删除。
- 任意勾选SKU的综合批量处理支持三字段keep/value，材质/尺寸还支持blank及手输尺寸；默认仅补待确认字段，显式覆盖才改已确认值。
- 按平台+店铺+商品ID分组，组级全选和“批量处理此商品”作用于该商品全部SKU，包括筛选隐藏行；弹窗明确显示范围和字段影响数。缺失ID逐行隔离。
- 同商品材质和厚度可一次修改，尺寸默认保持各SKU原值。只改材质会清除不匹配厚度并要求重新确认，不猜选另一材质的默认厚度。
- 提交先生成完整候选，任何非法输入均不产生部分修改；原文件与正式数据库不受影响。

新增验证覆盖跨店同ID、字段保护、伪亚麻、留空、按商品修改材质+厚度时保留尺寸、自定义尺寸及失败原子性。
