复核路径：

1. 商品规格标题行最右侧选择定价策略，切换面积 A（每 0.1㎡ +1 个百分点）与面积 B（+2 个百分点），观察 60×100、70×100 等规格目标毛利与售价。
2. 直接修改 SKU 售价，查看手动标识；切换策略、刷新后仍保留，可点击恢复。
3. 可复用规则 → 定价策略 → 编辑或新增，支持三种类型、自定义参数、复制、另存新方案；同种类型可保存多套。
4. 商品规格 → 展开设置 → 导入销售情况 → 试用销售示例，或下载示例表再导入。自动匹配 SKU ID 并回填销量和占比；相同报表重复导入不累加。
5. 商品转表 → 载入示例，体验按商品分组、缺失/未知/冲突厚度、伪亚麻和多尺寸复核。材质与尺寸可分别明确留空，厚度按所选材料计算重量成本；完成复核即可导出。
6. 商品规格 → 展开设置 → 保存当前尺寸方案，只填写名称。到可复用规则 → 尺寸方案编辑组合、复制或删除；选用时补入缺少尺寸，保留已有售价、占比与销量。
7. 定价策略、尺寸方案、材料、尺寸库、运费模板均可删除，并可在“显示已删除”中恢复。已有引用与历史账目保留。
8. 当前计划旁的“…”支持新建、复制、重命名、删除、恢复。删除最后一份计划后显示空态。
9. 备份与迁移可保存与恢复本轮原型 JSON 草稿，或重置示例。旧原型草稿自动升级，升级前保留原始备份。

界面使用“整体成交金额”和“整体支付 ROI 保本线”；商品规格默认收起设置，主工具栏保留显示设置和添加规格。定价名称与选择框合并，规则细则编辑集中在可复用规则。

## 上架价格计算器（第三轮）

- 商品规格右侧重复的铅笔按钮已删除，规格名称仍可进入该规格设置。
- 展开设置 → 上架价格计算器；默认不展开计算器，点击后弹窗。
- 当前策略价、手动售价均为用户最终到手价。选用一份活动方案，统一反推全部 SKU 的上架价；不改写到手价或盈亏计算。
- 可复用规则 → 活动方案，支持折扣、直减，多项叠加、调整顺序、编辑、复制、另存、删除和恢复。按用户补充，本轮不支持满减。
- 每一步以之前的金额为基础，四舍五入到分；反推活动后不低于目标到手价的最低分位上架价。例：上架 100 元 → 9 折 90 元 → 直减 5 元 → 到手 85 元。
- 结果可查看逐步计算明细并导出 Excel。每个计划记住自己的活动方案，旧草稿自动补齐新字段。
