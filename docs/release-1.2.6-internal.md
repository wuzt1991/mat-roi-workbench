## 本次变更

- 商品转表等待提示接入 [React Bits Lattice Loader](https://reactbits.dev/c/micro/lattice-loader) 官方默认效果。官方 CSS 原样保留，3×3 圆点环绕、6 px 圆点、2 px 间距、108 ms 逐点延迟、864 ms 周期及原缓动保持一致。保留计时，提示文字按上传、解析、复核和导出阶段显示；拖入文件、取消操作与动效偏好继续有效。
- 动画用同一起始时间恢复，解决 Windows 首帧绘制较慢时的时间丢失；页面切换和轮询重绘均不重播动画开头。
- SQLite 在首次访问前设置 5 秒锁等待；初始化失败关闭连接并保留原始错误。短暂占用可继续，持续占用有界失败并可重试。
- 文件子进程先确认完成结果已发送再退出；父进程等待 IPC 排空后判断结果。完成状态与释放任务占用同步发布，防止误报失败或下一次导入被上一任务阻挡。
- Electron 从 42.6.1 升级到 42.11.6，包含 Windows 退出时 `PostQueuedCompletionStatus` 无效句柄崩溃的 [42.x 官方修复](https://github.com/electron/electron/pull/53014)，包内 Node 为 24.19.0。
- 修复上传前文件名尚为空时恢复草稿登记失败的问题，新文件会话取得文件名后可以正常恢复。
- 包含此前已确认的施工内容：最新 29 列表头且两列条码留空、商品及销售文件拖入、按尺寸合并销量和回填占比、一键添加缺失尺寸、经营记录与总账调整、移除规格页另存完整定价方案，以及长表滚动修复。
