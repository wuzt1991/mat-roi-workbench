## 方案审核结论

方案可执行，但原文不足以直接证明以下边界，施工前已补充到 [修订方案](refactor-product-plan.md)：

1. 原界面每次重试创建新操作编号；结果未知时可能重复写入。现在先查原操作回执，明确未提交后才允许用户重试，且复用同一编号和请求内容。
2. 撤销没有回执，异步重算也缺少完整的结果核对。现在复用既有 `receipts` 表，在修改结果发布的同一事务中登记回执；活跃异步操作按 `broker.active.payload.command` 核对，不改变公开任务数据结构。
3. 页面销毁、迟到撤销、列表与 SKU 分开刷新存在状态风险。现在销毁使上下文失效；摘要和展开行只发布同一修订号的结果；读失败保留原视图并阻止基于旧列表继续修改、统一或导出。
4. 原性能脚本主要验证行分页，不能证明商品分组性能。新增三种 5 万行分布，并保留最终包的 50 万行容量验证。
5. 成品验证须证明真实可执行路径和数据隔离。报告记录载荷哈希、数据目录和桌面 profile；`MAT_DATA_DIR` 已能隔离两者，无需改桌面入口。

### 施工中发现并处理的问题

- 拆分后首次浏览器验证发现新增脚本遗漏 `defer`，早于识别模块执行；已修正依赖顺序，重新通过源码与成品窗口验证。
- 新旧导出测试最初误把流式读回的数字字符串和空字符串当成数字／null。按读取器实际合同比较值，同时独立检查 XML 类型；没有放松产品导出要求。
- 最终 Electron 窗口故障测试曾在单次网络拦截解除时影响随后发起的核对请求，出现超时／未知结果。保留拦截至核对结束后，同一成品通过；没有为通过测试改变产品代码。原失败日志保留。测试退出增加仅针对自己启动的子进程的退出兜底，避免失败后遗留窗口。

## 性能与容量

同一合成生成器、同机、每查询 20 次采样；两份原始输入哈希一致。下面为每种分布中最慢查询的 P95，并非平均耗时。

| 数据分布 | 基线 P95 | 候选 P95 |
| --- | ---: | ---: |
| 一个商品、50000 SKU | 187.80 ms | 182.61 ms |
| 10000 商品、每个 5 SKU | 182.70 ms | 181.80 ms |
| 10000 个同名不同身份商品、每个 5 SKU | 190.81 ms | 189.58 ms |

全部低于既定 500 ms 目标；这组差异只支持“未发现退化”，不宣称有显著提速。候选分组验证进程峰值 RSS 293.84 MiB。详见 `performance-comparison.json` 与两份原始分组报告。

最终成品运行时容量测试：

- 500000 行导入、单行修改与撤销、整商品 500000 行修改与撤销、导出及全部行回读通过；总耗时 292.52 秒。
- 深分页 P95 16.70 ms；单行修改 3.73 ms、撤销 0.36 ms；整商品修改 64.24 秒、撤销 78.47 秒。
- 导出回读行哈希相同：`f05d8bf443779ad6a1326b26754166716f11dd4af82214bd5501656f61131196`。
- 验证进程峰值 RSS 386.34 MiB，低于既有 512 MiB 断言。这不是整个 Electron 应用的总内存承诺。
- 500001 行按 `ROW_LIMIT` 拒绝，未进入有效导出会话；对应验证进程峰值 RSS 180.75 MiB。
- 原始报告：`final-large/report-500000.json`、`final-large/report-500001.json`。

## 维护边界与回退

静态影响核对：调整商品摘要字段主要落在 `views.js`；单 SKU／整商品输入校验主要落在 `model.js`；响应丢失协议在 `commands.js` 和服务回执边界。它们不需要同步改公式、SQL、历史账和导出器。本轮没有以文件数量或行数减少作为完成标准。

数据库结构和计算／导出协议未变；旧版存储引擎读取候选写出的合成会话通过。此证据不等于完成了整个用户 profile 的安装回退演练。当前没有替换本机，所以也不恢复任何施工前业务备份。

原施工目录所有基线文件与登记哈希一致；本机 1.2.10 的载荷仍为 `7535858c89a0c3998c94841a475ba2a28eb47fb26a1fe56a2d593aa5c9bcb38e`。测试只使用隔离数据与桌面 profile，没有写入真实业务数据。核对记录：`final-source-protection.json`。

Windows 1.2.11 的原生安装、覆盖升级、8 GiB 机器性能与 Excel/WPS 人工验收未执行。本轮只能交付源码与本地 Mac 候选的验证结果；阶段 3～4 的整体重构和正式发布不在完成声明内。
