# 地垫工作台：视觉与动效优化建议

> 本文为历史探索记录。施工以 [2026-09-19 确定版规格](ui-approved-spec-20260919.md)、[施工与验收步骤](ui-implementation-guide-20260919.md) 和随文冻结源码为准。最终为默认侧光、日间月白，两个主题都有微星粒子拖尾；下文旧方案和旧验证结果不代表最终版本。

## 历史：三套大胆案例

最新实现、参考来源及光影修正见 [材质与光影案例](ui-material-studies.md)。新增液态水晶、珠光折射、侧光剧场；侧光已接入 React Bits 原始 shader，并按反馈延长光影。预览左侧蓝色竖条已移除，鼠标反光改为平滑连续追随。

以下为上一轮材质探索与历史记录。

## 上一轮：材质探索

根据用户反馈，已撤下墨蓝侧栏和深色指标方向。当前保留原有浅色、蓝色操作与橙色入账体系，在同一预览入口提供“现有样式 / 磨砂玻璃 / 柔和陶瓷”。默认磨砂玻璃。下方第一、二版为历史记录，不代表当前推荐。

| 方案 | 可见质感 | 实现 |
|---|---|---|
| 磨砂玻璃 | 半透明白色表面，细亮边缘、柔和投影 | 外层面板 `backdrop-filter: blur(20px)`；菜单 24px、弹窗 28px；纯浅灰底 `#e9edf2`；内层指标不重复模糊 |
| 柔和陶瓷 | 哑光实体表面、柔和凸起卡片、内凹输入框 | 不透明浅色、双向柔光阴影、输入框内阴影；无背景模糊 |

两种方案保持字号、行高、间距、区域位置和控件尺寸。材料差异通过底色透明度、圆角、边缘反光和阴影实现。业务脚本仍复用原型，没有修改正式版。

背景调整：根据用户对底图的反馈，已移除斜向光带、色块和渐变，改为干净的纯浅灰底。面板材质、控件和动效不变。

本轮核对：两种方案分别在 1440×1000 / 390×844 下，与原样式的 382 / 328 个可见元素几何尺寸对比，差异为 0。菜单 Esc 焦点返回、弹窗打开取消、动效关闭均通过；实际样式确认菜单模糊 24px、弹窗模糊 28px。蓝色、橙色按钮保留可读的深色填充，表格提高底色不透明度。支持减少透明度和减少动态效果；未做低性能设备 GPU 性能验收。

第二版样式备份：`outputs/ui-refinement-20260918/ui-refinement-v2.css`（项目上级目录）。当前文件与入口名称不变。

## 第二版更新：让变化可见

用户反馈第一版静态差别过小，现有预览已更新为第二版。第一版细节记录保留在下文；颜色、圆角与动效参数以本节及当前预览 CSS 为准。

- 导航改为墨蓝 `#202e42`，工作区改为暖灰 `#f1f0ec`，白色内容面板使用 12px 圆角与可见的柔和投影。侧栏宽度、区域位置和控件尺寸不变。
- 首项非盈亏指标使用深蓝底和浅色字突出；盈亏卡按正负采用浅绿/浅赭红底，其他指标使用淡灰蓝底。原始数值、文案和字体大小保留。
- 输入框改为浅灰蓝凹入表面；橙色入账按钮增加底边与按压质感；表头、隔行底色、编辑行提示更清晰。
- 菜单 180ms、弹窗 220ms、导航与展开设置 180ms；保留减少动态效果支持。
- 当前对比入口顶部写明“第二版”，点击“现有样式 / 新版样式”可在同一工作区即时切换。

第一版样式已备份到项目上级 `outputs/ui-refinement-20260918/ui-refinement-v1.css`。本轮仍为独立预览，没有替换正式版。

第二版核对：桌面 382 个、手机 328 个可见元素的几何尺寸与原样式一致；菜单 180ms、弹窗 220ms 生效；Esc 关闭菜单后焦点返回；原有 11 个页面与业务文件哈希未变，新增脚本语法检查通过。

2026-09-18。结论：推荐沿用浅色工作台，借鉴 Linear 的安静层次，以及 Ant Design 的短促、功能性动效。保持现有区域位置、尺寸、信息密度、入口与业务流程，用色彩、边线、阴影和状态反馈改善体验。

## 推荐的外观方向

**安静、清楚、有轻微实体感的浅色桌面工作台。**

| 元素 | 建议 | 预览状态 |
|---|---|---|
| 工作区背景 | 减少蓝灰底的色偏，使用 `#f5f6f8` | 已演示 |
| 侧栏 | `#fcfcfd`，保持现有宽度；选中项增加 2px 内侧标记 | 已演示 |
| 文字 | 主文字 `#232933`、辅助文字 `#626d7c`；字号与行高不动 | 已演示 |
| 边线 | 采用低透明度深色，减少嵌套区域的框感 | 已演示 |
| 按钮 | 极轻顶边高光与底部阴影；橙色继续用于确认入账 | 已演示 |
| 弹窗与菜单 | 更柔和的多层阴影，保留现有尺寸、圆角与定位逻辑 | 已演示 |
| 表格编辑 | 焦点所在行淡蓝底 + 内侧标记，方便横向核对 | 已演示 |
| 字体、图标 | 延续本地 InterVariable、中文系统字体、Lucide；保持数字稳定 | 已保留 |

原项目已有等宽数字、焦点轮廓、Toast 淡入、弹窗背景虚化、移动端断点。这些不应被重复列为新增功能。不同状态继续保留文字与既有标识，颜色承担辅助作用。

## 动效参数

统一缓动建议：`cubic-bezier(.2,.8,.2,1)`。动效完成后的元素几何尺寸与原页面相同。

| 场景 | 动效 | 时间 | 实现边界 |
|---|---|---|---|
| 普通按钮按下 | 下移 1px，释放复位 | 100ms | 禁用按钮不参与；不推迟点击处理 |
| 店铺 / 计划菜单 | 透明度 + 3px 位移 + 0.985→1 | 150ms | 向上展开时反转位移；保留原定位、滚动和键盘处理 |
| 下拉箭头 | 旋转过渡 | 140ms | 使用已有展开状态 |
| 弹窗打开 | 透明度 + 6px 位移 + 0.99→1 | 180ms | 关闭立即执行，避免延迟焦点恢复 |
| 弹窗遮罩 | 淡入 | 160ms | 保留原模态行为 |
| 左侧页面 / Tab | 轻微透明度变化 | 140ms | 只由主动导航触发；不让每次数据重绘都播放 |
| 展开规格设置 | 透明度 + 3px 位移 | 160ms | 不做高度补间；收起沿用即时行为 |
| 减少动态效果 | 停止新增 CSS/WAAPI 动画 | 即时 | 尊重系统 `prefers-reduced-motion`；预览另外提供开关 |

预览只需要 CSS 与原生 Web Animations API，没有新增依赖。当前业务经常通过 `innerHTML` 整块重绘，因此不能给所有卡片、表格行统一挂载入场动画。数字更新应直接显示真实结果，不做滚动计数。

## 适用性取舍

优先使用：表格编辑反馈、菜单与弹窗层次、按钮按压、短切页动效。它们与现在的操作习惯兼容。

本轮不建议采用大面积玻璃拟态、发光边框、弹簧回弹、卡片倾斜、逐行入场或视差滚动。这类效果会分散长时间测算和核对表格时的注意力。当前也没有必要为了这一层微调引入 React 动效库、GSAP 或整套组件框架。

后续可单独评估“计算结果变化提示”：真实值立即更新，变化项背景短暂提示。需要在计算更新位置明确接入，不宜通过全页 DOM 观察器猜测变化；此次预览未实现。

## 核对结果与范围

- 在 1440×1000 视口比较工作区内 382 个可见元素，在 390×844 视口比较 328 个可见元素；精修与原样式的 x/y/width/height 无差异。
- 验证菜单使用 150ms 入场、弹窗使用 180ms 入场；Esc 关闭菜单后回到原触发器。
- 验证新建店铺与 SKU 编辑弹窗可打开并取消，展开设置可收起，编辑行背景与内侧标记生效，关闭动效后弹窗动画为 none。
- 系统减少动效路径已实现并检查源码；未修改系统设置进行实际模拟。
- 手机宽度下原有大金额换行现象仍存在。该问题涉及字号或响应布局，超出此次“保持布局”的视觉研究范围。
- 直接精修页和原复核页检查时未记录错误；内嵌对比页的浏览器日志出现 `MutationObserver.observe` 类型错误。新增脚本未调用 MutationObserver，直接页面未复现；尚未确定内嵌页错误来源，不声明完整无错误验收。需要避开此问题时可用上面的直接预览。
- 本次为方向研究与独立效果预览，没有完成正式版集成、全业务回归、安装包验收。

相关文件：`public/ui-refinement.css`、`public/ui-refinement-motion.js` 为视觉演示；`ui-refinement-frame.html` 与 `ui-refinement-sandbox.js` 负责独立入口；`ui-refinement-preview.*` 负责样式对比。

正式集成时先适配当前正式入口的事件名和弹窗选择器，再核对焦点、数据重绘、滚动位置和代表性业务页面。最终外观只需保留精修层，不需要加入预览工具栏。
