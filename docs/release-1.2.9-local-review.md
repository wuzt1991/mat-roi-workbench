# 1.2.9 本机检查版

2026-09-23。用户要求先替换本机检查，再决定是否进行 Windows 构建、测试和交付。当前已完成重设计、Mac 成品验证和本机替换；已安装版本为 1.2.9，并恢复原 334 条商品会话供用户检查。Windows 1.2.9 包未生成，未提交或推送远端。

## 最终交互

导入表格 → 同一步确认本表材质及统一厚度 → 确认导出。未识别材质或多材质歧义可在第二步统一指定，或分商品指定。按用户确认的厚度覆盖对应材质原表中的所有厚度。复杂尺寸或个别厚度例外进入手动调整：搜索商品、点修改、保存这一条。无自动补充弹窗、旧复核表格或批量工具栏。
