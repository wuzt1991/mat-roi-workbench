## 覆盖的业务和故障情形

- 公共材料复用、不同计划独立选择材料；调价只影响关联计划的当前测算。
- 长方形、异形外框、直接填写面积、用料系数、指定厚度、跟随材料。
- 按 100 个支付订单独立列账验证组合 ROI；低价占比从 0% 到 100%。
- 材料价、厚度、面积、SKU 售价及费用变更不修改历史快照。
- 无效数值、缺失报价厚度、占比不足、同日重复记录、损坏或篡改备份。
- SQLite 重启保留数据，事务保存，多窗口版本冲突阻止覆盖。
- 保存中继续编辑保留最后输入；保存失败保留草稿，恢复和重试。
- 记账、作废、同日补记、日期筛选、账目 CSV、恢复点下载、计划归档与恢复。
- 导入原型数据保留 3 个计划、3 种材料、7 个尺寸；测试数据只写入独立临时数据库。
- HTTP 来源校验、仅本机访问、服务端与数据库文件不能作为静态资源读取。

## 使用边界

两版使用本机数据库，跨电脑通过 JSON 导出/导入迁移，没有云端同步。Mac 包面向 Apple 芯片；不包含 Intel Mac 或 Windows ARM 原生包。Windows 版需要真机验收后再宣称运行通过。

计算是一单一件的均值模型，厚度按比例估算；补记过去日期仍使用填写时的参数，不会自动按过去日期匹配材料价。UI 和使用说明已说明这些口径。

自动恢复点保留全量旧版本，列表显示最近 100 个；数据库会随使用增长，未实施自动清理。恢复点与数据同机，应定期导出异地备份。
