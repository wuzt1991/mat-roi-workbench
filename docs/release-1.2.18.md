# 地垫工作台 1.2.18

- 毛利率、统一毛利、成本阶梯和面积递增定价统一按利润 ÷ 成本计算，成本包含材料、单次运费、平台费和税；活动逆算及上架价格表同步采用当前有效价格。
- 修复退款、分摊运费、销量分母与调整标记等关联计算，待核对尺寸不再产生有效策略报价；旧账保留冻结时的计算结果。
- 商品转表指定三列末尾固定带【材质、厚度】，厚度显示一位小数、不带 mm；原厚度精度继续用于材料成本及重量计算。
- 导出前可选择店铺，默认当前店铺，文件名使用“店铺名-YYYY-MM-DD.xlsx”。修复连续导出误取上一次文件的问题。
- 毛利率表头与 % 同排，保留底部公式说明并移除右侧重复小字。
- 改进旧备份兼容、工作区恢复、规则关联与大表处理，保留已确认的历史记录。

Windows 安装版通过“检查更新 → 下载更新 → 重启安装”更新。保存完成后再重启安装，升级保留已有数据。旧 ZIP 版或停在旧版本恢复页的用户可直接运行安装包覆盖安装，保留原数据目录。

Windows x64 安装包尚无商业代码签名。首次安装可能出现系统来源提示。macOS 不使用 Windows 在线更新通道。
