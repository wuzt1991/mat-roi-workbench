# 原型 v4：公共组合与表格编辑

本次落实六条浏览器批注。预览地址：http://127.0.0.1:4189/pricing-prototype.html?v=4

- 移除当前测算的包装重量字段；自动重量按材料系数与生产面积计算。原有手动计费重量可在表格填写，留空恢复自动。
- 公共资料新增规格组合页，集中创建与编辑名称、默认策略。计划引用公共组合；组合策略变更影响各引用计划的自动行。成本排名、订单占比仍在各计划内独立计算。
- 删除调整 SKU 弹窗、单行策略选择和售价模式选择。尺寸、材质、厚度、组合与占比直接编辑。
- 售价输入变更只把该行切换为手动价；保留其他自动行，可恢复策略价。非正数售价拦截，不写入持久化数据。
- 旧版单行策略的有效计算售价迁移为手动价，明细注明来源。旧版当前包装重量不再参与新版测算；旧历史记录保持原计算口径与金额。
