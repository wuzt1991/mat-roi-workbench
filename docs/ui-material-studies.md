## 当前保留方案（2026-09-19）

预览仅保留 **侧光模式** 和 **日间模式（月白）**。首次打开默认侧光；工作台右上角按钮显示可切换到的模式，点击直接切换，无需刷新。模式和动效偏好使用独立 localStorage 键保存，刷新及再次打开后恢复；不继承之前实验工具栏的 sessionStorage 选项。两个模式均启用微星粒子鼠标拖尾，菜单、弹窗等原有交互动效保留。当前仍为独立预览，正式入口未接入。

切换逻辑位于 `public/ui-appearance.js`，在首屏绘制前应用偏好。按钮挂在现有 `.topbar-right`，仅观察 `#app` 直属节点替换以应对业务重绘，不轮询、不观察业务子树。预览外层工具栏仅保留模式说明和动效开关。

性能策略：侧光不额外限制默认帧率或画布像素数，按设备显示刷新率与参考组件的 DPR 上限 2 渲染；粒子使用原生 DPR。觉得卡时可切换到日间月白模式，日间停止侧光背景渲染，仅在鼠标移动及尾迹消散期间绘制小范围粒子。隐藏页面、关闭动效或系统减少动态效果时，背景和拖尾均停止动画。不支持 WebGL 时保留静态暗色 UI，Canvas 2D 拖尾仍可使用。

验证：新偏好为空时默认侧光；切换到日间后刷新仍保留；导航重绘后按钮只有一个；Enter 键可以切换；390×844 下按钮可见。侧光背景调度验证在模拟 60Hz / 120Hz 下分别每秒绘制 60 / 120 次，证明没有默认帧率上限；日间、隐藏、关闭、减少动效时背景无持续循环，恢复侧光和可见后继续绘制。实屏连续截图确认光影仍在变化。未测量用户目标 Windows 设备的 GPU 占用、功耗或复杂业务负载，因此卡顿时应切换日间模式。

## 已确定：微星粒子（2026-09-19）

用户确定微星粒子后，侧光模式固定使用此拖尾；随后按用户要求，日间月白也启用同款拖尾。两个模式使用相同的粒子密度、108px 轨迹范围、420ms 消散时间及原生 DPR / 不限帧策略。侧光保留原色，月白使用低饱和银灰与灰绿色，以便在浅色底上看清。移除银光短尾、冰晶像素、试用选择器及演示逻辑。之前保存的试用选项不再读取，刷新后不会恢复到未选中的方案；模式和总动效开关仍保留偏好。当前改动仍在独立预览中。

## 前轮：鼠标拖尾试用（2026-09-19）

参考 React Bits 官方组件说明与源码注册表，筛选了 [Ribbons](https://reactbits.dev/animations/ribbons)、[Pixel Trail](https://reactbits.dev/animations/pixel-trail)、[Ghost Cursor](https://reactbits.dev/animations/ghost-cursor) 和 [Image Trail](https://reactbits.dev/animations/image-trail)。Ribbons 的细带形态、Pixel Trail 的消散方块适合缩小到工作台中；Ghost Cursor 的烟雾及 Image Trail 的图片覆盖面积偏大，本轮未接入。来源注册表：`https://reactbits.dev/r/{Ribbons,PixelTrail,GhostCursor,ImageTrail}-JS-CSS.json`。

本轮是借鉴形态后的原生 Canvas 2D 独立实现，没有复制上述组件代码，也没有引入 React / Three.js / OGL / GSAP。三个版本在预览顶部切换，附“关闭”和“播放演示”：

| 版本 | 表现 | 停止后的消散时间 |
|---|---|---|
| 银光短尾（预览初始选中） | 银白细线、浅冰青柔光、末端渐细 | 320ms |
| 微星粒子 | 小光点沿轨迹散开，间有四角星 | 420ms |
| 冰晶像素 | 3–4px 冰青方块，少量次级碎片 | 380ms |

轨迹中心距鼠标不超过 108px，粒子偏移后约 125px；鼠标尖端半径 7px 内留空。只使用一个 272×272 CSS 像素的透明画布，以原生 DPR 绘制，按屏幕刷新率运行，没有默认限帧或自动降清晰度。固定 64 个历史点用于保持短尾密度，插值跟随高速移动。停稳消散后停止拖尾循环；侧光背景保持原来的独立动画。

选择拖尾时不再叠加大范围面板扫光。画布不参与布局且不拦截点击，外层裁剪防止靠近屏幕边缘产生横向溢出；输入框、拖拽、滚动、离开窗口、页面隐藏时清空。日间月白、用户关闭动效、系统减少动态效果、非精确指针均不启用拖尾。侧光的拖尾偏好独立记忆，切到月白后保留选择但不绘制，回侧光恢复。演示运行约 2.2 秒后停止，真实鼠标移动会接管。

验证：三个版本分别通过模拟 60Hz / 120Hz 调度、DPR 3 原生画布尺寸、停稳释放循环、各启停条件、输入/触屏/按下安全及演示结束清理检查。浏览器查看三个演示、月白禁用状态和 390×844 工具栏；脚本语法检查通过。本轮仍仅修改独立预览；未做目标 Windows 设备 GPU 性能测试。

## 前轮：清淡珠光与局部跟随（2026-09-19）

根据最新反馈，撤下玫瑰、香槟的大面积彩色方案，提供三种近白色矿物配色：02A 冰青、02B 雾绿、02C 月白。侧栏、面板、菜单、弹窗与交互色同步，业务布局不变。推荐冰青 + 折射光环。

顶部独立选择鼠标动效，三个配色可以分别搭配以下任意效果（共 9 种组合），刷新后保留选择：

| 动效 | 范围与表现 |
|---|---|
| 折射光环 | 52px 的折射细环，外围柔光直径 96px，中心透明 |
| 细光弧 | 68px 与 40px 两道短弧，随指针位置轻微反向转动 |
| 微光尾迹 | 40px 主微光 + 28px 余光，余光与主光的距离上限 18px |

移除整面板扫光及大范围染色。珠光主光跟随时间常数 48ms，落后指针最多 14px；仍只在外层内容面板内显示，不拦截点击，跨子卡片不重置。停稳后结束动画循环，离开渐隐；动效关闭、减少动态效果和触控设备不启用鼠标光效。

本轮核对：三配色在 1440×1000 与当前原版的 382 个可见业务元素几何尺寸全部相同；390×844 工具栏无横向页面溢出，配色按钮在单独的横向滚动条内；逐一实屏查看三个配色及局部效果，自由搭配、跨子卡片连续跟随、动效关闭已验证。一次性 Node 调度验证覆盖连续跟随、14px / 18px 距离上限、停止后无空转及原有光影启停；JS 语法检查通过。

本轮未编辑正式业务文件。重新比较上一轮历史 SHA 基线时，发现三个 review 文件已有其他修改，因此不沿用“全体业务文件哈希不变”的旧结论；这次布局比较使用当前实际页面。

## 本轮修正

最初的侧光使用 Canvas 2D 模糊三角光束，速度与亮度过低，也不具备参考算法的波动。已替换成 Side Rays 原始 GLSL 算法。原版 shader 保持不变，使用满屏三角形和 requestAnimationFrame 驱动。

随后根据用户要求延长光影：`intensity` 从参考默认 2 调为 3.2，`falloff` 从 1.6 调为 0.85。速度 2.5、spread 2、top-right、tilt 0、saturation 1.5、blend 0.75、opacity 1、颜色 `#EAB308` / `#96c8ff` 均保留。算法相同，但容器比例、底色、面板遮挡和上述两个参数会使最终画面与参考演示不同，不能称为逐像素一致。

面板闪烁原因：旧版取鼠标目标最近的 `.metric` 或外层面板，跨卡片与缝隙时会清空原反光，再在新目标重设；还会重绘大面积背景渐变。已改为每个外层面板只有一个独立、裁剪且不拦截点击的柔光层。移动只更新 transform / opacity；约 85ms 的连续追随和 140ms 的渐隐，跨指标卡不会换层或重置亮度。底层卡片背景保持静态。

动效关闭、系统减少动态效果、页面隐藏时停止循环；鼠标效果仅用于精确指针。WebGL DPR 上限为 2。光影资源仅在切到侧光主题时初始化；支持 context lost/restored。未做低端设备 GPU 性能验收。
