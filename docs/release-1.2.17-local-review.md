# 1.2.17 本机内测更新

2026-09-29。按用户要求统一所有当前定价业务的成本毛利口径，并替换本机内测版。已安装并启动 `/Applications/地垫工作台.app`；本次只更新本机。

## 修复

- 统一毛利、成本排名阶梯、面积递增全部采用 `毛利率 = (售价 − 成本) ÷ 成本 × 100%`。成本含材料、单次运费、按售价计提的平台费和税；未计退款、广告及其他费用。
- 反推售价为 `基础成本 × (1 + 目标毛利) ÷ [1 − (平台费率 + 税率) × (1 + 目标毛利)]`。比率在公式中用小数表示；基础成本为材料加单次运费。金额用精确分数运算，向上取到分，避免低于目标或浮点尾差多收一分钱。不可达费率组合明确报错。
- 三种策略及编辑校验允许 100% 以上毛利。材料、厚度、尺寸、运费、费用变化，手动价/恢复策略、复制计划和取消策略同步检查。
- 活动逆算、界面到手价、后台价格表和 Excel 备份使用当前统一策略价。新格式 8 增加策略目标毛利列；格式 5/6/7 按旧可读内容验证后恢复。历史冻结售价和账目不重定价。
- 按用户后续要求移除表头旁重复小字，保留表格下方完整公式；“毛利率 / %”同排。保留此前商品转表厚度一位小数、无 mm 的输出。
