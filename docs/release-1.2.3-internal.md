# 地垫工作台 1.2.3 本地内测

日期：2026-09-21。销售导入复核增加“一键添加此尺寸”：销售表里有明确尺寸、当前计划没有时，可以直接补入计划，再应用销量与订单占比。保留拖入文件、人工映射与排除。本版继承 1.2.2 的完整施工功能；本次未推送、上传或在线发布。

## 使用行为

- 点击后标记“待添加”，继承计划有效默认材料、厚度、运费与定价方式。尺寸库已有相同尺寸时复用，长宽互换视为相同尺寸。
- 点击“应用订单占比”才把新尺寸、规格、销量、占比一起保存。取消添加、改为排除或放弃导入不会留下额外规格；保存失败可重试，不重复创建。
- 现有规格售价和商品/SKU 编号不变。撤销恢复原规格；本次新建尺寸未被其他计划或尺寸组合引用且未修改时一并清理。
- 无尺寸、多尺寸、计划内重复尺寸仍需人工映射或排除；默认材料、厚度或运费无效时提示先修正，不自行替换规则。
