# 地垫工作台 1.2.19

- 修复启动时恢复草稿失败的问题；恢复过程中断或响应丢失后，可重试，保留恢复前检查点。
- 非法数字输入会保留提示和原有有效数据，避免意外清空已保存值；主动清空仍按原有规则处理。
- 重量编辑草稿加入恢复范围，同时继续校验对应商品，避免恢复到错误商品。
- 修复合法小数退款比例在边界处被误拒绝的问题；真正超出比例上限的输入仍会阻止保存。
- 清理被拒绝上传遗留的临时文件，保留原文件、导入会话及成功任务的下载文件。
- 商品转表的货品名称与货品简称：硅藻泥 3.0、亚麻 3.5 的默认厚度只写材质；其他厚度继续保留一位小数厚度前缀。规格名称中的材质和厚度后缀保持不变。

Windows 安装版通过“检查更新 → 下载更新 → 重启安装”更新。保存完成后再重启安装，升级保留已有数据。旧 ZIP 版用户可直接运行安装包覆盖安装，保留原数据目录。已有账本冻结结果不重新计算。
